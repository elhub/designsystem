# Tokens

This component generates token maps to be used in Elhub design system stylesheets.

Here is where we specify color palletes, padding/margin/spacing values, 
typography fonts and sizes, among other parameters.

You do NOT need to install this package in your project.
Your project should use @elhub/ds-css instead, which provides all the tokens in convenient CSS stylesheets
